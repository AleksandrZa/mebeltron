# Работа с сайтом Мебельтрон

После каждого согласованного изменения сайта создавайте коммит и отправляйте его обычным push в main этого репозитория. Это постоянное пожелание владельца. Не используйте force push и сохраняйте чужие изменения.

Статический сайт расположен в корне: index.html, styles.css, app.js, assets/. Сохраняйте эту структуру.

На компьютере владельца основная копия Sites находится в D:/codex/sites/mebeltron/dist. Синхронизируйте обе копии при изменениях и обновляйте существующую публикацию Sites. Перед копированием проверяйте Git status и новые удалённые коммиты. Не загружайте исходные референсы, временные материалы, инструменты и секреты.
